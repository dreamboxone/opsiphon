# Opsiphon — سایفون برای OpenWrt (با رابط گرافیکی LuCI)

**نسخه ۱.۰.۰** · پشتیبانی و تماس: [t.me/routekernel1](https://t.me/routekernel1)
🇬🇧 **[English guide: README.md](README.md)**

Opsiphon کلاینت کنسولی متن‌باز
[psiphon-tunnel-core](https://github.com/Psiphon-Labs/psiphon-tunnel-core)
را به‌صورت یک سرویس واقعی OpenWrt اجرا می‌کند و یک صفحه LuCI هم برایش دارد،
یعنی تونل را به‌جای خط فرمان از رابط وب روتر روشن می‌کنی، وضعیتش را می‌بینی و
تنظیمش می‌کنی.

ساخته‌شده برای **OpenWrt 25.12**، تارگت `ipq40xx/chromium` و معماری
`arm_cortex-a7_neon-vfpv4`. اسکریپت‌های بیلد معماری‌های دیگر را هم پوشش می‌دهند.

---

## ۱) نصب

پکیج‌های آماده در پوشه `dist/` هستند:

```sh
scp dist/*.apk root@192.168.1.1:/tmp/
ssh root@192.168.1.1 'apk add --allow-untrusted /tmp/opsiphon-*.apk /tmp/luci-app-opsiphon-*.apk'
```

بعد در LuCI برو به **Services → Psiphon**.

بلافاصله بعد از نصب هیچ چیزی اجرا نمی‌شود: تونل خاموش می‌ماند تا خودت یک‌بار
دکمه **Connect** را بزنی. این عمدی است — تصمیم با توست که روتر از چه لحظه‌ای
ترافیک را تونل کند.

پیش‌نیازها (`jshn`، `libubox`، `luci-base`) بخشی از نصب معمولی OpenWrt + LuCI
هستند، پس برای نصب نیازی به اینترنت نیست.

نصب بدون پکیج:

```sh
./install-manual.sh root@192.168.1.1 arm_cortex-a7_neon-vfpv4
```

## ۲) صفحه LuCI

### پنل وضعیت

| فیلد | یعنی چه |
| --- | --- |
| **Connection** | `Stopped` سرویس خاموش · `Connecting…` روشن ولی هنوز تونل ندارد · `Connected` تونل برقرار است |
| **Egress country** | کشوری که ترافیک از آن‌جا از شبکه Psiphon خارج می‌شود — یعنی سایت‌ها فکر می‌کنند تو آن‌جایی |
| **Detected client country** | کشوری که Psiphon فکر می‌کند *تو* در آن هستی |
| **Connected for** | مدت زمانی که تونل فعلی برقرار بوده |
| **Traffic (down / up)** | حجم دریافتی / ارسالی از داخل تونل از زمان روشن شدن |
| **Local proxies** | آدرس پروکسی‌های SOCKS5 و HTTP که تونل در اختیار می‌گذارد |
| **Start on boot** | اینکه بعد از ریستارت روتر دوباره وصل شود یا نه |
| **Last event** | آخرین پیام (notice) سایفون — وقتی وصل نمی‌شود همین‌جا را نگاه کن |

پنل هر ۳ ثانیه به‌روز می‌شود.

### دکمه‌ها

| دکمه | چه می‌کند |
| --- | --- |
| **Connect** | مقدار `enabled=1` را ست می‌کند و سرویس را استارت می‌کند. تنها کلیدی که تونل را روشن می‌کند همین است. |
| **Disconnect** | `enabled=0` و توقف سرویس. |
| **Reconnect** | ری‌استارت سرویس — بعد از تغییر تنظیمات، یا برای گرفتن سرور دیگر. |
| **View notices** | لاگ پیام‌های اخیر سایفون (جدیدترین بالا) — برای عیب‌یابی. |

### تب General

| گزینه | چه می‌کند |
| --- | --- |
| **Start on boot** | بعد از ریبوت روتر خودکار دوباره وصل می‌شود. فقط وقتی معنی دارد که حداقل یک‌بار Connect زده باشی. |
| **Egress country** | کشور خروجی را مجبور می‌کند. حالت `Auto` (پیش‌فرض) یعنی خود سایفون سریع‌ترین سرور را انتخاب کند — تا وقتی کشور خاصی لازم نداری روی Auto بگذار. لیست کشورها از همان چیزی پر می‌شود که سایفون واقعاً موجود اعلام کرده. |
| **SOCKS5 port** | پورت پروکسی محلی SOCKS5 (پیش‌فرض `1080`). مقدار `0` یعنی غیرفعال. |
| **HTTP proxy port** | پورت پروکسی محلی HTTP (پیش‌فرض `8080`). مقدار `0` یعنی غیرفعال. |
| **Listen interface** | خالی یعنی پروکسی‌ها فقط از خود روتر در دسترس‌اند (`127.0.0.1`). اگر `br-lan` بگذاری، دستگاه‌های شبکه هم می‌توانند با `<آی‌پی روتر>:1080` استفاده کنند. |
| **Collect traffic statistics** | شمارنده‌های حجم مصرف را روشن می‌کند. اگر خاموشش کنی سایفون کمی کم‌حرف‌تر می‌شود. |

### تب Advanced

| گزینه | چه می‌کند |
| --- | --- |
| **Data directory** | جایی که سایفون لیست سرورها و دیتابیس داخلی‌اش را نگه می‌دارد. پیش‌فرض `/etc/opsiphon/data` است (بعد از ریبوت باقی می‌ماند). اگر فلش روتر برایت مهم است، روی حافظه USB بگذار، مثلاً `/mnt/sda1/opsiphon`. |
| **Establish timeout (s)** | اگر بعد از N ثانیه تونل برقرار نشد، از نو شروع کن. `0` یعنی مقدار پیش‌فرض خود سایفون. |
| **Limit tunnel protocols** | محدود کردن پروتکل‌های مبهم‌سازی (`OSSH`، `QUIC-OSSH`، `FRONTED-MEEK-OSSH` و…). همه را تیک‌نخورده بگذار — سایفون خودش طوری طراحی شده که هرکدام رد می‌شود را انتخاب کند. فقط برای تست اینکه کدام پروتکل از فیلتر عبور می‌کند به درد می‌خورد. |
| **Psiphon network** — *Sponsor ID*، *Propagation channel ID*، *Remote server list URL*، *Signature key* | این‌ها هویت کلاینت را به شبکه Psiphon معرفی می‌کنند. Sponsor ID و Propagation ID تعیین می‌کنند این کلاینت چه مجموعه سروری و چه صفحه خانگی‌ای بگیرد؛ آدرس لیست سرور جایی است که کلاینت لیست سرورها را از آن می‌گیرد و کلید امضا ثابت می‌کند آن لیست جعلی نیست. مقادیر پیش‌فرض همان **مقادیر عمومی متن‌باز** منتشرشده با psiphon-tunnel-core هستند. فقط در صورتی عوضشان کن که Psiphon Inc. کانفیگ اختصاصی به تو داده باشد. |

## ۳) بعد از اتصال، چطور از تونل استفاده کنیم؟

سایفون یک تونل با دو پروکسی محلی می‌سازد. فرستادن ترافیک به داخل آن یک تصمیم
جداگانه است:

**فقط یک دستگاه یا یک مرورگر:** در تب General گزینه *Listen interface* را
`br-lan` بگذار، بعد *Reconnect* بزن و در دستگاه مقصد تنظیم کن:

* SOCKS5 → `<آی‌پی روتر>:1080`
* HTTP → `<آی‌پی روتر>:8080`

**کل شبکه:** از یک مدیر پروکسی که می‌تواند همه ترافیک را ریدایرکت کند استفاده
کن، مثل PassWall2 یا OpenClash، و پروکسی سایفون را به‌عنوان upstream بهش بده:
یک نود از نوع `Socks5` با سرور `127.0.0.1` و پورت `1080` بساز و فعالش کن. از آن
به بعد خودِ آن برنامه ریدایرکت شفاف، DNS و قوانین بای‌پس (مثلاً بیرون نگه داشتن
سایت‌های داخلی از تونل) را انجام می‌دهد.

## ۴) خط فرمان

```sh
/etc/init.d/opsiphon start|stop|restart|status
opsiphon-stat                 # خلاصه وضعیت
opsiphon-stat -l              # به‌همراه آخرین پیام‌ها

uci set opsiphon.config.region='NL'
uci commit opsiphon
/etc/init.d/opsiphon restart
```

همه تنظیمات در `/etc/config/opsiphon` است و هر گزینه LuCI دقیقاً یک گزینه UCI
هم‌نام دارد.

## ۵) بیلد کردن

### هسته سایفون

نیازمند Go 1.26+ و git. چون CGO خاموش است، خروجی یک باینری استاتیک است که
بدون تغییر روی OpenWrt (musl) اجرا می‌شود.

```sh
./build/build-core.sh armv7      # ipq40xx / Cortex-A7 (پیش‌فرض)
./build/build-core.sh aarch64    # Filogic، Rockchip و…
./build/build-core.sh mipsel     # ramips / mt7621
./build/build-core.sh x86_64
```

خروجی: `prebuilt/<معماری>/psiphon-tunnel-core`.

### پکیج‌ها

```sh
./build/build-apk.sh arm_cortex-a7_neon-vfpv4 \
    ~/openwrt-sdk-25.12.5-*/staging_dir/host/bin/apk
```

این اسکریپت دقیقاً همان مراحلی را انجام می‌دهد که `include/package-pack.mk`
برای APK انجام می‌دهد (لیست فایل‌ها، conffiles با sha256، اسکریپت‌های نصب و
حذف) و بعد `apk mkpkg` را صدا می‌زند. چون چیزی کامپایل نمی‌شود، فقط به ابزار
`apk` از هر SDK نسخه ۲۵.۱۲ نیاز دارد — که کاربردی است، چون سیستم build کامل
OpenWrt روی فایل‌سیستم غیرحساس‌به‌حروف (مثل درایو ویندوز) اجرا نمی‌شود. آن را
با کاربر root اجرا کن تا مالکیت فایل‌های داخل پکیج `root:root` شود.

روی یک ماشین لینوکسی واقعی، مسیر SDK کامل هم کار می‌کند:

```sh
./build/build-package.sh ~/openwrt-sdk-25.12.5-<target> arm_cortex-a7_neon-vfpv4
```

## ۶) معماری داخلی

```
psiphon-tunnel-core  --stderr-->  opsiphon-notices (awk)  -->  /var/run/opsiphon/state
        ^                                                              |
        |                                                              v
/var/etc/opsiphon.json  <-- opsiphon-mkconfig <-- UCI      rpcd: luci.opsiphon  -->  LuCI
```

* `opsiphon-mkconfig` در هر بار استارت، کانفیگ JSON سایفون را از روی UCI می‌سازد.
* `opsiphon-notices` جریان پیام‌های سایفون را می‌خواند و وضعیت زنده و یک لاگ
  محدود (حداکثر ۴۰۰ خط) را در RAM نگه می‌دارد — هیچ چیزی روی فلش نوشته نمی‌شود.
* `luci.opsiphon` همان بک‌اند rpcd/ubus است که صفحه LuCI از آن وضعیت می‌گیرد و
  فرمان‌ها را به آن می‌دهد.

## ۷) نکته‌ها

* شناسه‌های پیش‌فرض، مقادیر عمومی متن‌باز هستند؛ مجموعه سرورها دقیقاً همان
  چیزی نیست که اپ‌های رسمی سایفون می‌گیرند.
* باینری هسته حدود ۲۰ مگابایت است — قبل از نصب روی دستگاه‌های کم‌فلش با
  `df -h /overlay` فضای خالی را ببین.
* برای عوض کردن لوگو: تصویر خودت را در مسیر
  `package/luci-app-opsiphon/root/www/luci-static/resources/view/opsiphon/logo.png`
  بگذار و دوباره بیلد کن.
